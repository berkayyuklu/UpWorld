# UPWORLD – Freelance Platformu

Modern, çift taraflı freelance platformu.

## Dosyalar
- `index.html` → Ana sayfa
- `freelancer.html` → Freelancer Portalı (yeşil-lacivert tema)
- `employer.html` → İşveren Portalı (sarı-siyah tema)
- `styles/` → CSS dosyaları
- `js/` → JavaScript dosyaları

## GitHub Pages ile Yayınlama
1. Repo oluştur, dosyaları yükle
2. Settings → Pages → Branch: main → Save
3. `https://kullanicin.github.io/repo-adi` adresinden erişebilirsin

## Özellikler
- Google ile giriş (simüle)
- Freelancer arama & filtreleme
- İş ilanı listeleme & filtreleme
- İlan verme (çok adımlı form)
- Freelancer & işveren paneli
- Detay modalları
- Responsive tasarım
